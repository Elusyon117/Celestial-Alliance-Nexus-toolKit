# Celestial Alliance Nexus Toolkit — Event Planner Update

This update contains the redesigned Event Planner / Mission Operations Dossier.

## Included changes

- Flight Profile Builder remains fully removed.
- Module Finder tooltips retained for FPS Loadout Manager and Cargo Grid Manager.
- Premium Mission Operations Dossier layout.
- Existing mission cover, briefing, ships, ship artwork, crew roles, assignments,
  priorities, drag/reorder, Discord/export, save/load, and autosave systems retained.
- Mission cover height synchronizes with Mission Briefing on desktop.
- Legacy cover-control strip and cover status pill removed from artwork.
- Wider fleet cards use the available Event Planner width.
- Horizontal Mission Timeline with left/right scrolling.
- Timeline steps alternate above and below the operation rail.
- Editable timeline step title, time, location, instructions, image, teams/personnel.
- Ships/units already added to the event can be assigned directly to timeline steps.
- Timeline ship assignments display the ship's existing cover artwork as thumbnails.
- Timeline data is included in Event Setup save/load.
- Timeline included in Complete Mission Board PDF.
- Dedicated horizontal timeline PNG export.
- Timeline exports contain a maximum of 4 mission steps per image/page.
- Activity cover thumbnail is intentionally omitted from timeline-only exports.

## Installation

Extract this ZIP into the root of the GitHub repository and replace the existing
`index.html`.
